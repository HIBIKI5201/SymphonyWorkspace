## 【要検証】PlayMode テストが3ファイルしか無い

**場所**: [Tests/Runtime/](../../Assets/SymphonyFrameWork/Tests/Runtime/)

| ファイル | テスト数 |
| --- | --- |
| `PauseAwaitableRuntimeTests.cs` | 10 |
| `SaveStoreAwaitableRuntimeTests.cs` | 7 |
| `SymphonyAwaitableRuntimeTests.cs` | 4 |

EditMode 側は33ファイル・約250テストあり、`internal` な内部実装まで
`InternalsVisibleTo` 経由で検証されている。**単体としての網羅は十分である。**

問題は **PlayMode でしか確認できない領域**の担保である。

| 領域 | PlayMode テスト | 備考 |
| --- | --- | --- |
| Pause | あり（10件） | – |
| SaveStore | あり（7件） | – |
| **SceneLoader** | **無し** | 実シーンのロード・アンロード・Activeシーン切替 |
| **AudioManager** | **無し** | `AudioSource` の実挙動、ミキサー連携 |
| **ServiceLocator** | **無し** | `DontDestroyOnLoad` を跨いだ解決 |
| **SymphonyDebugHUD** | **無し** | `OnGUI` 描画 |
| **static 状態のリセット** | **無し** | Play Mode 2往復でのゴースト参照検出 |

`SceneLoader` は670行の `SceneLoadService` を持つ最大のサブシステムで、
**シーンのロード順・優先度・Activeシーン切替という、EditMode では原理的に検証できない
振る舞いが中心にある**。ここにPlayModeテストが無いのは網羅の穴として大きい。

### なぜ「要検証」か

`Documentation/CONTRIBUTING.md` §4 は「テストで再現できない範囲は
`Samples/Runtime/*Sample/` のサンプルシーンと手動確認で担保する」と定めている。
**方針としては明文化されている**ため、これが意図的な線引きなのか、
単に追随できていないのかは判断できない。

### 修正方針

まず **Play Mode 2往復でstatic状態が残らないことを検証するテスト**を1本追加することを勧める。

- 観点[03](03_ライフサイクルとstatic状態のリセット.md)の唯一の未実施項目がこれである
- Domain Reload 無効という当フレームワーク固有の前提を、唯一自動で守れる手段になる
- サブシステム個別ではなく `SymphonyOrchestrator` の初期化・リセットを対象にすれば1本で済む

`SceneLoader` のPlayModeテストはその次の優先度になる。

## 【設計指摘】サンプルの配置がUPM規約から外れている

**場所**: [Samples/](../../Assets/SymphonyFrameWork/Samples/)

`Samples`（チルダ無し）に置かれているため、サンプルスクリプトが
`SymphonyFrameWork` アセンブリへコンパイルされ、利用側の全ビルドへ出荷される。
**詳細と修正方針は [B1](B1_公開APIの妥当性.md) に記載している**（最優先指摘1件目）。

本観点からの補足として、サンプルの内容自体は良く追随している。

- `package.json` の `samples[]` 6件と `Samples/Runtime/` のディレクトリ6件が**過不足なく一致**している
- 各サンプルに `displayName` と日本語の `description` が付いている
- `PauseManagerSample_Mover` が `PauseManager.IPausable` を実装しており、
  **`IPausable` の唯一の実装例になっている**（→ [14](14_KISS原則とYAGNI.md)）

## 検証したが問題が無かった項目

- **`LogAssert.ignoreFailingMessages` の使用は0件。**
  `CONTRIBUTING.md` が禁じている（ログを無視するだけで消費しないためテスト間へ漏れる）
  アンチパターンが混入していない
- **テスト用 asmdef 2件はいずれも `includePlatforms: ["Editor"]` または
  `UnityEngine.TestRunner` 参照を正しく持つ**
- **サンプルの名前空間が `SymphonyFrameWork.Samples.<サンプル名>` で統一されている**
