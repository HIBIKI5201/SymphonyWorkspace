## 【設計指摘】既定値 `grace = 120` が3箇所に重複している

**場所**: [SymphonyLocateObject.cs:48](../../Assets/SymphonyFrameWork/Runtime/Component/SymphonyLocateObject.cs)、
[ServiceLocator.cs:345](../../Assets/SymphonyFrameWork/Runtime/System/ServiceLocator/ServiceLocator.cs)、
[ServiceLocator.cs:405](../../Assets/SymphonyFrameWork/Runtime/System/ServiceLocator/ServiceLocator.cs)

```csharp
// SymphonyLocateObject.cs:48
public Awaitable<T> GetInstanceAsync(byte grace = 120, CancellationToken token = default)

// ServiceLocator.cs:345
byte grace = 120,

// ServiceLocator.cs:405
byte grace = 120,
```

サービス解決を待つ猶予フレーム数の既定値である。**同じ値が3箇所に literal で書かれている。**

### 何が問題か

**片方だけを変更すると、APIによって既定の待機時間が食い違う。**
`SymphonyLocateObject.GetInstanceAsync` は `ServiceLocator` への薄いラッパーであり、
利用側から見れば同じ機能の別入口である。既定値が揃っていることは仕様の一部にあたる。

これは単なるマジックナンバーではなく**知識の重複**であり、
[13 DRY](10_13_コード重複とDRY.md) の観点でもある。

また `120` という値そのものにも情報が無い。
`Application.targetFrameRate` が 60 なら2秒、30 なら4秒であり、
**フレーム数なのか時間なのかが読み手に伝わらない**。

### 修正方針

`Core/SymphonyConstant.cs` へ定数を追加し、3箇所から参照する。

```csharp
/// <summary> サービス解決を待つ既定の猶予フレーム数。60fpsで約2秒。 </summary>
public const byte DEFAULT_SERVICE_LOCATE_GRACE_FRAMES = 120;
```

**既定値パラメータは呼び出し側へインライン展開される**ため、
定数化しても利用側の再コンパイルが必要な点は変わらない。挙動は変わらない。

命名は同ファイルの既存定数（`SYMPHONY_FRAMEWORK`）に合わせた
SCREAMING_SNAKE_CASE とする。

## 検証したが問題が無かった項目

### `GetHashCode` の `397` / `17` / `31` は定数化しない

22件が該当するが、これらは**ハッシュ結合の慣用素数**であり、
Rider / ReSharper が生成する標準形である。名前を付けても読みやすくならない。

```csharp
hashCode = (hashCode * 397) ^ (DataTypeName?.GetHashCode() ?? 0);
```

**8つの値型すべてで書き方が統一されている**ことのほうが重要で、そこは守られている。

### 単位変換の値は自明

| 場所 | 値 | 判定 |
| --- | --- | --- |
| `SymphonyHUDDrawer.cs:98-100` | `1024` | バイト単位変換。自明 |
| `SymphonyHUDDrawer.cs:79` | `1000.0f` | 秒→ミリ秒。自明 |
| `SymphonyHUDDrawer.cs:37` | `50` | フォントサイズの画面高比。**要検討**（下記） |
| `SymphonyHUDDrawer.cs:47` | `0.1f` | 移動平均の平滑化係数。**要検討**（下記） |

`50` と `0.1f` は意味が読み取りにくいが、**いずれも `SymphonyHUDDrawer` 内の1箇所にしか
現れない**。重複していないため、`SymphonyConstant` へ出す必要は無い。
`private const` とコメントで足りる。

```csharp
private const int FONT_SIZE_SCREEN_HEIGHT_RATIO = 50;
private const float DELTA_TIME_SMOOTHING = 0.1f;
```

**これは任意の改善であり、指摘としては挙げない。**
