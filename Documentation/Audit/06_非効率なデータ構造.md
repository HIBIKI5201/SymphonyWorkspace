`struct` の `IEquatable<T>` 宣言、コレクションの探索方式、レジストリの実装を確認した。

## 【要検証】`SaveDataEntryInfo` に等価性の実装が無い

**場所**: [SaveDataEntryInfo.cs:6](../../Assets/SymphonyFrameWork/Runtime/System/SaveSystem/SaveDataEntryInfo.cs)

```csharp
public readonly struct SaveDataEntryInfo
{
    public Type DataType { get; }
    public SaveDataContent Data { get; }
    public bool IsLoaded { get; }
}
```

`Equals` / `GetHashCode` / `IEquatable<T>` のいずれも実装されていない。
比較が発生すると `ValueType.Equals` のリフレクション経路へ落ち、
**フィールドごとのボックス化とリフレクションによる比較**が起きる。

### なぜ「要検証」か

**この型が実際に比較されているかを追い切れていない。**
`SaveStore.GetEntries` が返す集合に対して利用側が `Contains` / `Distinct` / `IndexOf` を
呼べば発生するが、フレームワーク内部では比較していない。

**利用側のコード次第で影響が変わる**ため確定にはしない。

### 対になる実装がフレームワーク内にある

**同じ役割の他の値型は、すべて等価性を実装している。**

| 型 | `IEquatable` | `GetHashCode` |
| --- | --- | --- |
| [SceneLoadInfo](../../Assets/SymphonyFrameWork/Runtime/System/SceneLoader/SceneLoadInfo.cs) | あり | あり |
| [SceneLoadRequest](../../Assets/SymphonyFrameWork/Runtime/System/SceneLoader/SceneLoadRequest.cs) | あり | あり |
| [ServiceRegistrationInfo](../../Assets/SymphonyFrameWork/Runtime/System/ServiceLocator/ServiceRegistrationInfo.cs) | あり | あり |
| [PauseInfo](../../Assets/SymphonyFrameWork/Runtime/System/Pause/PauseInfo.cs) | あり | あり |
| **SaveDataEntryInfo** | **無し** | **無し** |

**`*Info` 型のうち、これ1つだけが例外である。** `SceneLoadInfo` を
テンプレートとしてそのまま横展開できる。

**修正方針**: `IEquatable<SaveDataEntryInfo>` を宣言し、`Equals` / `GetHashCode` /
`operator ==` / `operator !=` を `SceneLoadInfo` と同じ形で実装する。
**`public` 型への実装追加なので破壊的変更にはならない**（既存の比較結果が
リフレクション経路と一致する限り）。

## 検証したが問題が無かった項目

- **レジストリはすべて `Dictionary` ベース。** `SceneLoadRegistry`（`Dictionary<string, ...>`）、
  `ServiceLocateRegistry`（`Dictionary<Type, ...>`）ともにO(1)探索である。
  `List.Contains` による線形探索は見つからなかった
- **`GetHashCode` の実装が8件すべて同じ形（`(hash * 397) ^ ...`）で統一されている。**
  ReSharper/Riderの生成形式に揃っており、書き方が割れていない
- **Editor側の [AssetStoreToolsPackageContext](../../Assets/SymphonyFrameWork/Editor/Generator/AssetStoreToolsPackager/AssetStoreToolsPackageContext.cs)
  も `IEquatable` 未宣言だが、`[Obsolete]` 済みで削除予定である**（→ [B2](B2_Obsoleteとドキュメント同期.md)）。
  指摘しない
